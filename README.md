
# CV Creation and Printing Tool

This project is a simple yet powerful tool designed to help you prepare and print your CV in an A4 format with a single "print" command. The resulting output is a PDF that is formatted and ready to be used for professional purposes.

## Project Overview

- **Purpose**: The main goal of this project is to allow users to easily create a CV that can be printed directly from the browser into an A4-sized PDF.
- **Technologies**: The project is built using HTML, CSS, and JavaScript. It leverages modern web technologies to ensure the CV is responsive and print-ready.

## Features

- **Responsive Design**: The CV is designed to fit perfectly on an A4 page when printed.
- **Custom Styling**: The `style.css` file contains all necessary styles to ensure that the CV is well-formatted and visually appealing.
- **One-Click Print**: Users can simply open the HTML file in a browser and use the print function to generate a PDF.

## Usage Instructions

1. **Open the Project**: Download or clone the repository to your local machine.
2. **Customize Your CV**: Edit the `index.html` file to fill in your personal details, skills, education, and work experience.
3. **Print to PDF**:
   - Open `index.html` in your web browser.
   - Use the browser’s print function (Ctrl + P or Command + P on macOS).
   - Select "Save as PDF" in the print dialog.
   - Ensure the page size is set to A4 and margins are set to "none".
   - Click "Print" to save your CV as a PDF.

## Project Structure

- `index.html`: The main HTML file containing the structure of your CV.
- `style.css`: The CSS file responsible for styling the CV and ensuring it is print-ready.

## Customization

- **Styling**: Modify the `style.css` file to change colors, fonts, and layouts according to your preferences.
- **Content**: Update the `index.html` file to include your personal information, photo, and other relevant details.
